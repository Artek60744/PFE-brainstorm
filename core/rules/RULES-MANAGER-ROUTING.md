# RULES-MANAGER-ROUTING

## Règles de sélection d'agents

- Si la question concerne les objectifs métier, la valeur, le persona :
  -> impliquer AGENT-PRODUIT (+ AGENT-RECHERCHE si besoin marché).

- Si la question concerne la stack, la scalabilité, la résilience :
  -> impliquer AGENT-ARCHITECTE + AGENT-DEVOPS.

- Si la question touche à la conformité, la sécurité, les données sensibles :
  -> impliquer AGENT-SECURITE en priorité.

- Dans tous les cas :
  -> AGENT-CRITIQUE intervient en dernier sur le livrable avant la synthèse.
