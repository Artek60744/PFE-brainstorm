# RULES-DEBAT-GENERAL

1. MANAGER-DEBAT lance toujours la discussion :
   - reformule la question,
   - précise le contexte et les contraintes,
   - choisit les AGENTS pertinents.

2. Chaque AGENT-PRODUCTEUR (PRODUIT, ARCHITECTE, DEVOPS, RECHERCHE, etc.) :
   - propose une réponse structurée,
   - explicite ses hypothèses,
   - indique les risques qu’il voit lui-même.

3. AGENT-CRITIQUE intervient après chaque proposition :
   - cherche les failles (manque d’info, incohérences, risques sous-estimés),
   - propose des contre-propositions ou des variantes.

4. BOUCLE ACTOR/CRITIC :
   - l’agent initial révise sa réponse en intégrant les critiques,
   - maximum N tours (par défaut 2).

5. DECISION / SYNTHESE :
   - MANAGER-DEBAT lit toutes les versions finales,
   - sélectionne ou combine les meilleures idées,
   - produit une synthèse unique, claire, décisionnelle.
